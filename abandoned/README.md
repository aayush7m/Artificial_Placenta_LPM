# Abandoned work

Approaches that were tried and deliberately backtracked out of. Kept because the
reasoning behind each dead end is worth not re-discovering. Nothing here feeds any
current model.

- **`resistor_only/`** — the AP circuit modelled as pure resistors, before inductors
  were added. Replaced by `analysis/inductor_resistor_fit.py`.
- **`prototypes/`** — from-scratch fetal circulation models predating the
  `AP_model_vN` series.

All scripts here are **frozen**: paths were not updated during the reorganization,
and they are not expected to run as-is. See each subfolder's README.

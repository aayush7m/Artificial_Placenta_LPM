# Artificial_Placenta_LPM — Fetal Cardiovascular Lumped-Parameter Models

Lumped-parameter (LPM) models of the fetal circulation connected to a pumped
artificial placenta (AP) circuit, fitted against a March 2024 ECMO trial recording.

Topology follows Pennati et al. (Med Biol Eng Comput, 1997). The current model is
**`models/AP_model_v18.py`**.

```
├── poster/               Poster figures (from analysis/make_poster_plots.py)
├── superseded/           v4–v13. Linear ancestry, superseded but valid.
└── abandoned/            Dead ends. Work that was deliberately backtracked out of.
```

Every model version that ever ran is still here; the split is between *what came
before the current version* (`superseded/`) and *what was tried and rejected*
(`abandoned/`). The clinical recordings are not distributed — `data/README.md`
describes the CSV format the loaders expect.

`models/AP_model_v15_temp.py` and `models/AP_model_v18_temp.py` are byte-identical
working copies of `AP_model_v15.py` and `AP_model_v18.py`.

### v18 and the identifiability analysis (Aug 20)

v18 is the first model in this lineage whose parameters come with **confidence
intervals and identifiability verdicts** rather than hand-tuning. The pipeline:

| Script | Role |
|---|---|
| `analysis/ap_cost.py` | chi-square cost `J` over 8 phase-invariant features of the AP trace |
| `analysis/profile_likelihood_v17.py` | circuit re-fit, 62-parameter scan, profile likelihood |
| `analysis/sensitivity_v17.py` | local sensitivity, collinearity, joint re-fit |
| `analysis/make_v18.py` | generates `models/AP_model_v18.py` from the fit |
| `analysis/make_poster_plots.py` | poster figures in `poster/` |

**The headline result is negative, and it is the point:** of 62 homeostatic
mechanism parameters, **0 are identifiable**, 15 are practically
non-identifiable (bounded on one side) and 47 are structurally
non-identifiable. Three circuit constants alone take J from 541.06 to 0.120;
fitting six mechanism parameters on top of that reaches only 0.0925.

Three reasons, all documented in the scripts:

1. **The recording contains ~3 independent numbers.** The AP circuit is a chain
   of fixed R–L elements driven by Q and anchored at P_UA, so `dp_ecmo`,
   `dp_restr`, `dp_pump_mean` and `p_pre_ecmo` are algebraic consequences of
   mean flow and UA pressure, not independent constraints.
2. **The influential parameters are mutually redundant.** Every parameter the
   data respond to sets cardiac output, and AP flow measures cardiac output, so
   they trade off against each other. `cat_G_HR`'s apparent depth collapses
   222x once its substitutes are free to compensate.
3. **`fs_alpha` and `fs_V_ref_frac` are exactly redundant.** In
   `ventricular_pressure`, `sat = 1/(1 + fs_alpha*(V_eff/V_ref)^2)`, so the two
   enter only as `fs_alpha / V_ref^2`. Measured collinearity r = -1.000. No
   dataset can separate them; this is a property of the model, not the data.

Constraining the slow mechanisms (edema, RAAS, AVP, regurgitation) needs a
recording hours long — their time constants are 1800–36000 s against a 30 s
window. Constraining the fast ones needs a hemodynamic perturbation, not a
steady trace.

**Known limitation:** profiles were run at `INNER_MAXITER = 6→4` to fit an
overnight budget, so the curves are jagged rather than smooth. Under-convergence
raises profiles, so every non-identifiable verdict is safe (conservative); the
curves would only flatten further with more iterations. Re-run at 10-12 for
publication-quality figures. Also, 12 of the 21 qualifying parameters were
profiled; the other 9 are reported from their scans and are excluded from the
fit selection, because a scan depth is an upper bound and is not comparable to
a profile depth.

### Resolved: the three circuit constants (Aug 12)

The values hardcoded in v15/v16 — `40.545318`, `268.787`, `0.002471` — are the good
ones. `optimizer_v1.py`'s old saved best (`21.0823` / `85.676` / `0.051013`) was a
**bad fit that the optimizer could not escape**, because `BOUNDS` was centred on the
v14 *baseline* and excluded the working values:

| Parameter | Old bounds | Working value | |
|---|---|---|---|
| `R_AO4_UA` | [2.81, 14.76] | 40.545 | 2.7x above the upper bound |
| `V_BLOOD_TOTAL` | [58.1, 305.1] | 268.787 | inside |
| `C_UA` | [0.0263, 0.1380] | 0.002471 | 10.6x below the lower bound |

Scored with the optimizer's own cost function, the working values beat its "best"
9x (0.107 vs 0.963). With `C_UA` trapped >10x too large, the umbilical artery
compliance buffers away the pulsatility: flow amplitude collapses to 2.1 mL/min
against a clinical 40.1, and that single term is 98% of the unreachable cost.

Verified at the same time:

- `optimizer_v1.py` optimizes **absolute values, not multipliers** (`build_model`
  overwrites the whole `3.9 * R_factor` product; `to_z`/`to_params` are plain
  log/exp round-trips).
- **v15 uses all three constants correctly** — `res_AO4_UA` and `cap_UA` are assigned
  absolutely (correctly *not* scaled by `R_factor`/`C_factor`), and the `145.229`
  literal in `x0[0:23] *= BLOOD_VOLUME/145.229` is exactly v14's un-scaled baseline
  total (145.229232), so the post-scaling total really is `BLOOD_VOLUME` mL.
- A full diff confirms **v15 = v14 + those three constants and nothing else**, so
  optimizing v14 with absolute overrides is equivalent to optimizing v15.

Fixes applied to `optimizer_v1.py`:

1. `BOUNDS` re-centred on the working values (same x0.4–x2.1 window).
2. Model metrics resampled onto a uniform time grid before averaging, so they are
   time-weighted like the 10 Hz clinical trace rather than weighted by Radau's
   adaptive step density. This also removed nearly all of the coarse-vs-fine
   solver bias (mean flow 179.553 @ 0.01 vs 179.556 @ 0.002; it was 174.6 vs 178.7).
3. Two-stage fidelity: search at `max_step=0.01`, then a full-fidelity polish phase
   at `0.002`. Skip with `--no-polish`.
4. The fresh-start point is now the v15/v16 working values, not the v14 baseline
   (which now falls outside the bounds).

The pre-fix state file is kept at
`results/optimizer/archive/optimizer_state_PRE-BOUNDS-FIX_2026-07-29.json`.

## The two backtracks

**1. Resistor-only → R–L series (the inductor switch).**
The AP components (ECMO, restrictor, tubing) were first modelled as pure resistors,
fitted by `resistor_fit.py` (Jun 17) and then `resistor_fit_v2.py` (Jun 22, adds
z-score outlier removal). A pure resistor sets the mean flow but cannot reproduce
the flow *amplitude* — so each component was remodelled as a series R–L
(`dP = R·Q + L·dQ/dt`), where R sets the mean and L attenuates the pulsatile
component. `inductor_resistor_fit.py` (Jul 22) replaced both resistor scripts, and
v13 was the first model to use its output. The resistor-only scripts are in
`abandoned/resistor_only/`.

**2. Pre-versioned prototypes → the AP_model series.**
`one.py`, `two.py`, `three.py` (May 26 – Jun 8) were successive from-scratch fetal
circulation models; `main.py` + `params.py` were a separate radius-based attempt.
All were abandoned when the `AP_model_vN` series started at v4. They are in
`abandoned/prototypes/`.

## Running things

Set up an environment and install the dependencies:

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
```

Then put the clinical recording in `data/` (format in `data/README.md`), or point the
scripts at it with the `ECMO_CSV_PATH` environment variable.

Every script runs directly from the project root and resolves its own paths — no
`PYTHONPATH` or `-m` needed:

```bash
python3 models/AP_model_v18.py                    # current model: simulate + compare to clinical
python3 analysis/inductor_resistor_fit.py         # re-fit the AP circuit R-L pairs
python3 analysis/optimizer_v1.py --show           # print optimizer's best-so-far
```

The v17 → v18 identifiability pipeline, in order (see `results/README.md`):

```bash
python3 analysis/profile_likelihood_v17.py        # circuit re-fit, parameter scan, profiles (hours)
python3 analysis/sensitivity_v17.py               # sensitivity + joint fit -> fitted_parameters.json
python3 analysis/make_v18.py                      # regenerate models/AP_model_v18.py
python3 analysis/make_poster_plots.py             # poster figures
```

Archived scripts under `superseded/` and `abandoned/` are **frozen** — their paths
were not updated. To run a superseded model, pass the data path explicitly:

```bash
ECMO_CSV_PATH="$PWD/data/ECMO_Trial_2024-03-05_cleaned_v2.csv" python3 superseded/AP_model_v13.py
```

`abandoned/resistor_only/` additionally needs `pandas`, and `abandoned/prototypes/main.py`
imports an `old.params` module that is not in this repository.
